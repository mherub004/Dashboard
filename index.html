SERVER CONNECTION

Meet your infrastructure

Run the agent on your Linux Docker server. It sends metrics here every 30 seconds over HTTPS.

  1. Clone the repository on your server.
    git clone https://github.com/mherub004/Dashboard.git
cd Dashboard
cp .env.example .env
  2. Copy your connection settings into .env.
  3. Set DOCKER_GID from this command, then start the agent.
    stat -c '%g' /var/run/docker.sock
docker compose up -d --build
The token grants permission to send telemetry. Keep it private. No public server port is needed.
